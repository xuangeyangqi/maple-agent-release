# MapleAgent 版本清单

本仓库只存放「冒险岛脚本助手」的版本信息与下载链接，**不含任何源码或凭据**。

客户端启动时会读取本仓库的 `version.json` 判断是否有新版本，仅做**提示**，不会自动安装。

## 字段说明

| 字段 | 含义 |
|---|---|
| `version` | 最新版本号，语义化版本 |
| `notes` | 更新说明，客户端会展示给用户 |
| `url` | 安装包下载地址（留空表示暂无下载） |
| `min_version` | 低于此版本将强制提示更新 |
| `released_at` | 发布日期 YYYY-MM-DD |

## 发版流程

1. 构建安装包，上传到可公开下载的位置（网盘/OSS 直链）
2. 修改 `version.json` 的 `version` / `notes` / `url` / `released_at`
3. 提交，客户端下次启动即看到提示

**注意**：本仓库是公开的。不要在这里写任何内部信息、服务器地址、卡密、密钥。
